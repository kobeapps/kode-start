# Rick and Morty API Project
Projeto flutter sobre personagens de Rick and Morty para o processo seletivo da KODE.

Na aplicação: 
Padrão simples de flutter, com compenentização para simplificar o código.
Classe home - página principal do projeto com cards padronizados expandíveis de cada personagem. Clicar causa o card a expandir e mostrar mais informações, e mantendo pressionado abre uma outra página com aquele card apenas.
Classe CharModel - Declaração dos atributos e construção do personagem com factory e JSON.
Classe CharPage - Página única para cada personagem.
Arquivo ApiService - Principal função de buscar os persogens e suas informações da Rick and Morty API.
Classe buildCustomAppBar - Componente padrão da barra superior.
